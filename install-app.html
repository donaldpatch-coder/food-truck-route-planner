Open the app ↗

Made for your home screen

Install the web app on your phone or computer, or use it directly in your browser. No separate app subscription is required.

How to install

iPhone / iPad: open this page in Safari, tap Share, then Add to Home Screen. Enable Open as Web App if offered, then tap Add.

Android: open in Chrome and tap Install above when offered, or use the browser menu → Install app / Add to Home screen.

Computer: open in Chrome or Edge and choose Install from the address bar or browser menu.

This is an installable web app. It is not an Apple App Store or Google Play download.

After your first connected visit, the owner app shell and browser-saved tools can open offline. Sign-in, syncing, live weather, public listings and reviews require internet. Local records belong to the browser and device where you saved them; installation does not transfer records from the previous hostname.

Keep the original tools

  • Dashboard, check-in timer and broadcast flow
  • Location and weather search, route plans and CSV export
  • Sales logs, costs, profit reports and location history
  • Suppliers, operations, permits and reminders
  • Social queue, POS tools, marketplace and community
  • Business profiles, public space listings, settings and help

The original MVP limits still apply: live social posting needs configuration; Square/Toast integrations and calendar export are not finished integrations.
